# João Bonifácio — Personal Website & Portfolio

Welcome to the repository for my personal academic & professional website: **[bonijoao.github.io](https://bonijoao.github.io/)**.

##️ Built With

- **Framework**: [Quarto CLI](https://quarto.org/)
- **Core Engine**: [R](https://www.r-project.org/)
- **Design System**: Custom SASS (`styles.scss`) with a sleek black theme
- **Hosting & Deploy**: GitHub Pages via GitHub CLI (`gh`)
