## 📌 About This Site

This site serves as my digital hub to showcase research, software development, academic publications, interactive Shiny applications, and technical blog posts.

- **[Home](https://bonijoao.github.io/)**: Overview of my research background in Physics, Statistics, Time Series Analysis, and Machine Learning.
- **[R Packages](https://bonijoao.github.io/pacotes/)**: Open-source R packages published on CRAN ([`deriva`](https://CRAN.R-project.org/package=deriva) and [`tidyprf`](https://CRAN.R-project.org/package=tidyprf)).
- **[Shiny Apps](https://bonijoao.github.io/shiny/)**: Interactive web applications built with R Shiny (ProbCalc, cor_xy, DeSta, Brasileirão).
- **[Data Analyses](https://bonijoao.github.io/analises/)**: Reproducible statistical reports and case studies.
- **[Blog](https://bonijoao.github.io/blog/)**: Articles on statistics, mathematics, physics simulations, and data science in R.
- **[CV / About](https://bonijoao.github.io/cv.html)**: Academic formation at UFLA, research interests, ORCID, and Lattes links.

## 💻 Running & Rendering Locally

To clone, edit, and preview this website locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/bonijoao/bonijoao.github.io.git
   cd bonijoao.github.io
   ```

2. **Render the entire site**:
   ```bash
   quarto render
   ```

3. **Preview live with auto-reload**:
   ```bash
   quarto preview
   ```
